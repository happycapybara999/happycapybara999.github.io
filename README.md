# Plan zajęć — GitHub Pages

To jest statyczna wersja aplikacji, gotowa do publikacji przez GitHub Pages.

## Publikacja

1. Utwórz nowe repozytorium na GitHubie.
2. Wgraj do repozytorium zawartość tego folderu:
   - `index.html`
   - `manifest.webmanifest`
   - `icon-512x512.png`
   - `favicon-32x32.png`
   - `apple-touch-icon.png`
3. Wejdź w **Settings → Pages**.
4. W **Build and deployment** wybierz **Deploy from a branch**.
5. Wybierz branch `main` i folder `/ (root)`.
6. Zapisz ustawienia.

Po chwili GitHub poda adres strony.

## Ważne

Wersja jest całkowicie statyczna — nie potrzebuje Node.js, Next.js ani instalowania zależności.
